# Cepheus SARIF viewer

A self-contained, offline static viewer for Cepheus SARIF reports. Open
`web/index.html` in any modern browser, drop a SARIF or JSON file
generated by `cepheus analyze`, and explore the findings + chain
visualizations interactively. Ships with light and dark themes.

Everything runs in the browser — no server, no network calls, no data
leaves the page.

## Usage

Produce a SARIF report:

```sh
cepheus analyze posture.json --format sarif --output report.sarif
```

Open the viewer:

```sh
# macOS
open web/index.html
# Linux
xdg-open web/index.html
# Windows
start web\index.html
```

Drop `report.sarif` onto the page. The left pane shows the findings
table sorted by severity; click any row to see the chain visualization
and detail panel on the right.

A sample SARIF report (`web/sample-report.sarif`) generated from the
K8s Goat T1-system-monitor fixture ships alongside the viewer so you
can verify the viewer works before producing your own scan.

## What it shows

| Pane              | Content                                                                                  |
|-------------------|------------------------------------------------------------------------------------------|
| Summary stats     | Counts of critical / high / medium / low findings.                                       |
| Findings table    | One row per Cepheus chain (`runs[0].results[]`), severity-sorted, with composite score.  |
| Chain visualizer  | Left-to-right ordered node graph of the techniques in the selected chain.                |
| Detail panel      | Severity, affected component(s), impact, and recommendation up top; then message, reliability/stealth/confidence sub-scores, compliance crosswalk, and the technique reference URL. |

## Filtering

* Free-text search (top of left pane) is a multi-token AND match across
  rule id, title, technique ids, chain id, message, impact,
  recommendation, affected components, and compliance ids.
* Severity dropdown narrows to critical / high / medium / low / info.
  Cepheus emits the exact severity on each result; for third-party SARIF
  without it, the `level` field maps error→high, warning→medium,
  note→low, none→info.

## Notes

* The viewer reads vanilla SARIF 2.1.0. It will load any SARIF report,
  but the chain-graph view depends on Cepheus's
  `properties.techniques` and `properties.chain-id` extensions —
  third-party SARIF files render as single-node "chains" of the
  rule id alone.
* Offline-first: no CDN, no web fonts, no analytics, no external
  fetches — system font stacks only, all processing client-side.
* Structure: `index.html` (markup + inline CSS), `viewer.js` (pure,
  DOM-free SARIF helpers, unit-tested with `node --test "web/**/*.test.js"`),
  and `viewer-ui.js` (DOM rendering — all report-derived content inserted
  via `textContent` / `createElement`, never `innerHTML`).
